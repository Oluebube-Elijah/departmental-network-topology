# departmental-network-topology
Departmental network topology design, IP addressing, and connectivity testing using Cisco Packet Tracer.
About This Project

This project demonstrates my practical networking skills using Cisco Packet Tracer. I designed a simulated network connecting computers across different departments.

Objectives

* Design a departmental network topology.
* Configure IP addresses for network devices.
* Test connectivity between computers across departments.
* Practise network interfaces and end-to-end communication.

Tools Used

* Cisco Packet Tracer

Skills Demonstrated

* Basic network topology design
* IP addressing
* Network connectivity testing
* Basic connectivity troubleshooting

What I Learned

This project helped me understand how devices communicate across a simulated departmental network and how IP addressing supports network connectivity.
